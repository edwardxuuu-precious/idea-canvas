# 想法画布

在浏览器打开 [想法画布.html](想法画布.html) 即可离线使用。这份 HTML 同时是 Mac 桌面版和本机同步浏览器的界面，由 `src/` 下的源码拼成。

## 体验 2.1

打开 Mac 上的「想法画布」，进入「市场观察方式」。想试会保存的操作，可以先用「文件 → 导出可编辑 HTML」，再双击打开导出的文件，在浏览器里使用这一份离线副本。

详细版本变化、更新原因与实现记录见 [更新日志（CHANGELOG.md）](CHANGELOG.md)。

1. **切换布局**。点顶部「布局」，试试「中心双侧」和「上下树形」。选样式会立即预览，点「取消」或按 `Esc` 可回到原来的位置和缩放。以后要按同样的布局再排一遍，直接点旁边的「自动整理」。树形布局会按当前折叠状态分配空间。应用布局和自动整理都可以用 `⌘Z` 整步撤销。
2. **调整一部分节点**。选中「黄金分割」，点底部的整理分支按钮。也可以按住 `Shift` 点选多张卡片，再在「布局 → 整理范围」选择「所选节点」。在面板里可指定中心主题，切换紧凑、标准、舒展，或分别调同级间距和层间距。
3. **固定、对齐和分布**。选中一张卡片，点底部图钉可固定整理时的位置。多选后试「对齐」，选中至少三张可做等距分布。手动拖动靠近其他卡片的边缘或中心时会出现参考线。
4. **试专题排列**。用「时间轴」沿顺序横向铺开，用「鱼骨图」看主干和分支。用「分类矩阵」同时看两项分类。行按「状态」、列按「卡片类型」时，状态为「待配图」、类型为「想法」的卡片会排入两者交叉的格子。同一格有多张卡片时会尽量并排。自由摆放适合手动整理。
5. **修改外观**。点「样式 → 画布」，设置背景色、强调色、网格颜色、疏密和类型。选卡片后进入「卡片」页，可以多选后批量改类型、文字、填充、边框和形状。点「恢复继承样式」可恢复到画布或分支提供的样式。
6. **设置分支和连线**。选分支起点或分支线，在「样式 → 分支」调整颜色、形状、粗细和虚实，子分支会继承。点一条普通关系线，在「连线」页可单独设置线条和箭头，双击关系线可编辑文字。在「画布」页保存一个主题后，切到另一张画布也能应用它，卡片和线条单独设置的样式优先显示。
7. **用状态和标签筛选**。在「样式 → 状态」可自定义状态名称、图标、颜色和顺序，也能管理彩色标签。选中一张或多张卡片后可分配状态、多个标签和优先级或星标。已分配的状态可从卡片上的状态标记打开。点顶部眼睛图标，组合选状态和标签，按需淡化其他卡片或只显示匹配卡片及其上级。
8. **阅读和导航**。在「视图 → 阅读」切换标题、摘要和完整正文。有子卡片的节点在分支出口显示折叠按钮。收起时的数字表示下一层的卡片数。每次点击只打开一层。向右逻辑图、中心双侧和上下树形会重新排布当前分支，画布会跟进到可阅读的位置。需要全部打开时，点「视图 → 阅读 → 展开全部」。点底部靶心聚焦分支，按 `Esc` 恢复视野。点顶部大纲图标后，点标题定位，拖住大纲右侧把手调整同级顺序，后续布局会采用该顺序。
9. **建立分区**。多选卡片后点底部「建立分区」图标，在分区面板里改名称和颜色。拖动画布上的分区名称，成员卡片会一起移动。

在分类矩阵中拖动卡片，松手时会更新目标格的行列属性。`⌘Z` 会一起恢复属性和位置。在旧矩阵里，点一下「自动整理」可以展开空分类。

## 键盘、命令和导出

- 按 `⌘K` 搜索画布和卡片。输入 `>` 只列出命令，例如「自动整理画布」「导出 PNG 图片」「切换为深色外观」。
- 选中卡片后，方向键会切换到那个方向上最近的卡片，`⇧` + 方向键会加选。`⌥` + 方向键按像素微调位置。
- 拖动卡片时，卡片边缘或中线靠近其他卡片会自动吸附。按住 `⌥` 拖动可以关闭吸附。
- 把卡片拖到另一张卡片上停留约 0.35 秒，目标卡片显示「松手设为子分支」，松手后改挂到它下面。树形布局会立即重排，`⌘Z` 可撤销。
- 「文件」菜单可以导出 PNG、SVG 和 Markdown。选中一张卡片时，只导出它所在的分支。
- 本机 AI 或另一个浏览器改动画布时，当前的视野、选中和筛选保持不变，被改动的卡片闪一下高亮。

## 修改界面源码

界面源码在 `src/`。`src/index.html` 是页面骨架，`src/styles/` 和 `src/scripts/` 按功能分文件，`<!-- @include … -->` 行标出它们拼入的位置。

改完 `src/` 后运行下方命令，重新生成单文件 `想法画布.html`。

```sh
tools/bundle.sh
```

`./build.sh` 会先运行这一步。`bun test` 会检查 `想法画布.html` 和 `src/` 是否一致，直接改 `想法画布.html` 会让检查失败。

## 构建与版本备份

在安装了 Xcode Command Line Tools 的 Mac 上，从项目目录运行下方命令。

```sh
./build.sh
```

构建生成 `dist/想法画布-macOS.zip`。将压缩包解开到 `~/Applications` 即可取得已签名的 App。Swift 源码、图标和应用配置位于 `macos/`。

每次运行 `./build.sh` 会自动在 `dist/releases/v<版本号>-b<构建号>/` 保存带版本号的完整离线归档，包含：

- `想法画布-macOS-vX.Y.Z-bN.zip`（对应版本桌面端安装包备份）
- `想法画布-vX.Y.Z-bN.html`（对应版本单文件离线画布备份）
- `RELEASE-NOTES.md`（从 [CHANGELOG.md](CHANGELOG.md) 提取的当期更新说明）
- `manifest.json`（构建时间、Git Commit、文件大小与 SHA-256 校验值）

需要回退任意历史版本时，可从 `git checkout vX.Y.Z` 或直接解压 `dist/releases/` 中对应版本目录的安装包/HTML。

## 查看画布和预览

桌面版和已配对的浏览器读写同一份本机数据，文件位于 `~/Library/Application Support/想法画布/画布数据.json`。从桌面版的「文件」菜单可以打开数据目录或复制浏览器同步链接。

桌面版更新后，刷新原有的浏览器同步页面即可加载新版。离线 HTML 的编辑由打开它的浏览器保存。要把离线编辑带到另一处，在原画布的「文件」菜单导出可编辑 HTML 或 JSON。

本机项目的 `previews/` 有自动整理和图文编辑的界面预览。
